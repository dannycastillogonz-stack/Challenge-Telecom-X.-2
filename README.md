Este proyecto tiene como objetivo aplicar el proceso ETL (Extract, Transform, Load) para limpiar y transformar datos del sector telecomunicaciones y posteriormente construir un modelo predictivo utilizando los datos tratados.

El análisis permite preparar datos de forma eficiente y generar predicciones basadas en información previamente procesada.

𖦹 Objetivos

Extraer datos del dataset original.

Limpiar y transformar los datos.

Preparar los datos para análisis.

Construir un modelo predictivo.

Evaluar el rendimiento del modelo.

𖦹 Tecnologías utilizadas

Python

Pandas

NumPy

Scikit-learn

Google Colab

𖦹Resultados

Se logró construir un modelo predictivo utilizando datos previamente procesados mediante ETL.
El modelo fue capaz de generar predicciones basadas en los datos tratados y mostrar su desempeño mediante métricas de evaluación.
